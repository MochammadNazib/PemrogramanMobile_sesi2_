# Prototype WebView – MIT App Inventor

##  Deskripsi Project

Project ini merupakan tugas kelompok mata kuliah **Pemrograman Mobile** yang berjudul **Prototype WebView menggunakan MIT App Inventor**.

Aplikasi ini dibuat sebagai bentuk implementasi pembelajaran pengembangan aplikasi mobile menggunakan platform MIT App Inventor. Project ini bertujuan untuk memahami proses pembuatan aplikasi Android dengan memanfaatkan komponen WebView.

##  Tujuan Project

1. Memahami dasar pengembangan aplikasi mobile.
2. Mengenal dan menggunakan platform MIT App Inventor.
3. Memahami penerapan komponen WebView pada aplikasi Android.
4. Menghasilkan prototype aplikasi mobile dalam bentuk file APK.
5. Melatih kerja sama dan kolaborasi dalam pengerjaan tugas kelompok.

##  Tools dan Teknologi

- **Platform:** MIT App Inventor
- **Komponen:** WebView
- **Operating System:** Android
- **Output:** APK (Android Package)

##  Cara Instalasi dan Menjalankan Aplikasi

1. Download file `Tugas1.apk` pada repository ini.
2. Pindahkan file APK ke perangkat Android.
3. Buka file APK yang telah diunduh.
4. Izinkan instalasi dari sumber yang tidak dikenal apabila diminta.
5. Tekan tombol Install.
6. Setelah proses instalasi selesai, buka aplikasi.
